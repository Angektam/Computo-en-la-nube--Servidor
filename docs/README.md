# Documentación y entregables

Esta carpeta reúne los materiales académicos y de apoyo del proyecto, separados del código ejecutable.

## Carpetas

- `entregables/`: prácticas, reportes, evidencias y documentos entregados.
- `presentaciones/`: diapositivas y PDF de la presentación E2.
- `referencias/`: apuntes, respuestas y archivos de consulta.

El código de la aplicación permanece en `src/` y `public/`. Los scripts de infraestructura están en `deploy/`, las pruebas en `test-local/` y los generadores de documentos en `scripts/generators/`.
